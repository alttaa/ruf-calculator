# How to work with Alex

- Alex is a novice at Python projects (beyond simple scripts) and new to React. macOS user.
- This is a learning project: explain, don't just write code for him.
- Short chunks, one idea at a time. Concrete numbers before abstract symbols
  (e.g. "Ah = 12 × 4 + 2 = 50" before "card = rank × 4 + suit").
- Prefer giving Alex the code to type himself in small pieces, then have him run it.
  Write files directly only when he asks you to.
- After each new idea, ask 1–3 small check questions and wait for his answers.
- Flag "fork points" (other methods/designs worth knowing) briefly; take the simple path first.
  When Alex picks a fork, record it in docs/DECISIONS.md.
- Every new function gets a pytest test. Run the tests before saying something works.
- Be direct when unsure; don't assert.
